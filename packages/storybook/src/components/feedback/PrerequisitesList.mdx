# PrerequisitesList

List of required conditions with complete or incomplete status indicators.

The `PrerequisitesList` groups prerequisite items in a semantic list.

Each `PrerequisitesList.Item` pairs a label with a status icon and can include a short description.

## Demo

## Usage

### When to use

- Users need to see a set of prerequisites and whether each one is complete.
- A prerequisite needs a short label and optional supporting detail.

### When not to use

- When statuses require more detail than complete or incomplete.
- When the content isn't a set of prerequisites.

### Best practices

- Render each condition as a `PrerequisitesList.Item`.
- Set `status` to `complete` or `incomplete` based on the current condition.
- Add a description only when the label doesn't provide enough context.
- Keep status meaning available through each item's label, not only its icon.

## Content and copy

- Write labels as concise conditions users can recognize quickly.
- Use descriptions for necessary context, not to repeat the label.
