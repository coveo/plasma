# Switch

Toggle control for turning a binary setting on or off.

The `Switch` communicates the current state of an independent setting and lets users change it directly.

Use `Switch.Group` when several related settings remain independent from one another.

<Canvas of={SwitchStories.Demo} />

## Usage

### When to use

- Users turn a true binary setting on or off.
- The control represents states such as enabled, visible, or active.
- Several independent settings share one category.

### When not to use

- For mutually exclusive options, use a `Radio` or `SegmentedControl`.
- For selecting any number of options from a set, use a `Checkbox`.
- For destructive or irreversible actions, use an explicit confirmation flow.

### Best practices

- Give every switch a visible, programmatically associated label.
- Describe the active state, not the action of toggling it.
- Add a concise description when users need to understand the setting's effect.
- Keep grouped switches independent. Use a different control when only one option can be active.
- Show the current state when a switch is disabled or read-only.

## Content and copy

- Use labels such as **Email notifications**, not **Enable email notifications**.
- Keep descriptions to one sentence and explain the result of turning the setting on.
