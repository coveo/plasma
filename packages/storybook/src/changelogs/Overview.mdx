# About Changelogs

Everything that changed in Plasma — components, tokens, patterns and documentation — in one feed.
The per-component changelog at the bottom of each component page answers the same question for that component alone.

A changed rule disrupts as much as a changed prop, so guidance changes are in the same list — not in a section underneath.
