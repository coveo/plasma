    Patterns
</Header>

Patterns are guidance, not building blocks. Components and templates are what you build with; a pattern is a rule
about how to use them. Each pattern answers "what should happen when this situation comes up?", such as confirming a
destructive action, communicating feedback, or choosing between a switch, a checkbox, and a radio. Some patterns
combine several components; others help you pick the right one.

Core patterns apply everywhere in Coveo products. Product patterns apply to a single product and are documented with
that product.

Every pattern follows the same structure: summary, when to use, when not to use, decision guide, how it works, rules,
content, accessibility, examples, and related components.
