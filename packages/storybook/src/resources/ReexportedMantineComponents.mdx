# Re-exported Mantine components

Plasma re-exports about 90 Mantine components unchanged, with Coveo theming applied.
This page says what that means for you.

## What you get

- Coveo theming and tokens, applied automatically through `Plasmantine`.
- Version upgrades handled by the Plasma team.
- Mantine's own documentation for the API, props and examples.

### What you don't get

- Coveo usage guidance, copy rules or accessibility expectations. If one of these components becomes load-bearing in a Coveo product, [ask us to promote it to core](https://url.coveo.com/plasma-request).

```tsx
// always import from Plasma, never from @mantine/*
import {Accordion, Carousel} from '@coveord/plasma-mantine';
```
