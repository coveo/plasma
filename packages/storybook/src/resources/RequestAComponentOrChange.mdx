# Collaboration and contact

Plasma is built with the teams that use it.
Most of what gets added, changed or clarified starts with someone saying something was missing — so saying it is the contribution.

You do not need a finished proposal, and you do not need to be sure.
Pick whichever of these matches how settled your question is.

## Start with a question

<SlackChannel /> is the shortest path, and the right one more often than the form is.

Ask there when you are still working out what you need — whether something already exists, which component fits the case you have, whether a gap is worth a request or is better built in your own product for now, or how another team solved the same screen.

An answer in the channel often removes the need for a ticket.
When it does not, we will say so, and you will open one already knowing what to write in it.

The channel is also where releases are announced: the changelog is mirrored there.

## Open a request

When you do need something from the team, the form opens in Jira with the **Design System** project and the right issue type already selected.
You only fill in what the request is.

- **[Request a component, a change or a bug fix](https://coveord.atlassian.net/secure/CreateIssueDetails!init.jspa?pid=17244&issuetype=10105)** — Something is missing, something should work differently, or something is broken in a component. You do not have to decide which — we classify it in triage.
- **[Report a problem in the documentation](https://coveord.atlassian.net/secure/CreateIssueDetails!init.jspa?pid=17244&issuetype=10105&labels=documentation)** — The page is wrong, unclear or out of date, and the component is fine. Same form, arriving tagged `documentation` so it is triaged as a docs fix rather than a code change.
- **Fix the documentation yourself** — A typo, a wrong example, a stale link. The **Edit this page** link in any page footer opens the source on GitHub in your browser and turns your edit into a pull request — no local setup, no ticket.

Found it on a specific page?
The **Report a problem** link in that page's footer opens the second form, already tagged and already carrying the page it came from.

## Before you open it

Thirty seconds that save a round trip.
None of these disqualify a request — they change what we do with it, and most of them are worth a message in the channel first.

## What happens next

<Unstyled>
    <Steps>
        <Step>
            <strong>Within 48 hours</strong> — someone from the Plasma team responds. Not a decision, a human.
        </Step>
        <Step>
            <strong>Within a week</strong> — a direction: we build it, you build it in the extended layer, or it is not
            a Plasma problem.
        </Step>
        <Step>
            <strong>Within two weeks</strong> — a decision, at the latest, with the reasoning written in the ticket.
        </Step>
    </Steps>
    <Note>
        A commitment about process, not delivery dates. <strong>You build it</strong> is a normal outcome rather than a
        refusal — it usually means the need is real but not yet shared by enough teams to belong in Plasma. Tell us when
        you have built it; that is what makes it a candidate later.
    </Note>
</Unstyled>
