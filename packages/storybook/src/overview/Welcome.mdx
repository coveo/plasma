## Where things are

- **Foundations** — tokens, colour, type, spacing, iconography, accessibility.
- **Content** — voice, mechanics and vocabulary.
- **Components** — one list by job, with the library each one comes from.
- **Patterns** — how components go together, and what the combination has to get right.
