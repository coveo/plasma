# Install and setup

Three ways to consume Plasma — in code, in Figma, and from an AI assistant.
Set up the one you need; they do not depend on each other.

## In code

Install Plasma with its required peer dependencies.

```bash
npm install @coveord/plasma-mantine @mantine/core @mantine/hooks react react-dom
```

Add the optional Mantine packages only when your application uses their components.

```bash
npm install @mantine/carousel @mantine/code-highlight @mantine/dates @mantine/form @mantine/modals @mantine/notifications
```

Wrap the application once in the `Plasmantine` provider, and import the base stylesheet.
The provider applies the Coveo theme and the tokens to every component below it, so no separate `MantineProvider` is needed.

```tsx
import {Plasmantine} from '@coveord/plasma-mantine/plasmantine';
import '@mantine/core/styles.css';

export function App({children}) {
    return <Plasmantine>{children}</Plasmantine>;
}
```

Each optional package ships its own stylesheet, imported the same way.

```tsx
import '@mantine/notifications/styles.css';
```

<Unstyled>
    <Rule>
        Always import from <code>@coveord/plasma-mantine</code> — never from <code>@mantine/*</code> directly.
    </Rule>
    <Note>
        This holds for the ~90 re-exported Mantine components too. Importing them from Mantine bypasses the Coveo theme
        and pins you to a version Plasma does not control. See <strong>Re-exported Mantine components</strong>.
    </Note>
    <Worked>
        You will know it worked when a <code>Button</code> renders in Coveo blue rather than Mantine's default, with
        no further configuration.
    </Worked>
</Unstyled>

## In Figma

<Unstyled>
    <Steps>
        <Step>
            Enable the <strong>Plasma</strong> library in your file, under Assets.
        </Step>
        <Step>
            Enable the <strong>Plasma Tokens</strong> variable collection, so colour, spacing and radius resolve to the
            same values the code uses.
        </Step>
    </Steps>
</Unstyled>

Components carry the same names in Figma and in code, so a handoff can name one thing.
Where a Figma component has no code equivalent, or the reverse, the **Components overview** says so in the Figma column.

<Unstyled>
    <Worked>
        You will know it worked when a colour on your layer resolves to a <strong>semantic</strong> token name — not a
        raw primitive like <code>blue-5</code>, which is not for direct use.
    </Worked>
</Unstyled>

### Set up your AI tool

For the best results, install the Plasma skill and configure both MCP servers in your AI tool:

- The **Plasma skill** gives your agent persistent setup, import, and documentation lookup conventions.
- The **Plasma and Mantine MCP servers** give your agent access to the entire design system documentation efficiently.

<Accordion variant="filled">
    <Accordion.Item value="claude-code">
        <Accordion.Control>Claude Code</Accordion.Control>
        <Accordion.Panel>
            **Step 1: Install the Plasma skill.** Save [`plasma-skill.md`](/plasma-skill.md) as `~/.claude/skills/plasma/SKILL.md` so it is available in all your projects. Alternatively, save it as `.claude/skills/plasma/SKILL.md` in your project to share it with your team.

            **Step 2: Configure the MCP servers.** Add both servers at the user scope so they are available in all your projects:

            ```bash
            claude mcp add --scope user plasma -- npx -y @coveord/plasma-mcp-server
            claude mcp add --scope user mantine -- npx -y @mantine/mcp-server
            ```

            Alternatively, to share the setup with your team, add both servers to a project-scoped `.mcp.json` at your repository root and commit it:

            ```json
            {
                "mcpServers": {
                    "plasma": {
                        "command": "npx",
                        "args": ["-y", "@coveord/plasma-mcp-server"]
                    },
                    "mantine": {
                        "command": "npx",
                        "args": ["-y", "@mantine/mcp-server"]
                    }
                }
            }
            ```

            Run `/mcp` in Claude Code to verify both servers are connected.
        </Accordion.Panel>
    </Accordion.Item>
    <Accordion.Item value="codex-cli">
        <Accordion.Control>Codex CLI</Accordion.Control>
        <Accordion.Panel>
            **Step 1: Install the Plasma skill.** Save [`plasma-skill.md`](/plasma-skill.md) as `.agents/skills/plasma/SKILL.md` in your project.

            **Step 2: Configure the MCP servers.** Add both servers to `~/.codex/config.toml`:

            ```toml
            [mcp_servers.plasma]
            command = "npx"
            args = ["-y", "@coveord/plasma-mcp-server"]

            [mcp_servers.mantine]
            command = "npx"
            args = ["-y", "@mantine/mcp-server"]
            ```

            For a project-specific setup, set `CODEX_HOME=.codex` and add the configuration to `.codex/config.toml`.
        </Accordion.Panel>
    </Accordion.Item>
    <Accordion.Item value="github-copilot-cli">
