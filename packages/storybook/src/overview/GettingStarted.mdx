# Plasma

Plasma is Coveo's design system for the Administration Console.
It provides Mantine-based React components, design tokens, icons, and content guidelines for Coveo products.

## Getting Started

### Installation

Install Plasma with its required peer dependencies:

```bash
npm install @coveord/plasma-mantine @mantine/core @mantine/hooks react react-dom
```

Install the optional Mantine packages only when your application uses their components.

```bash
npm install @mantine/carousel @mantine/code-highlight @mantine/dates @mantine/form @mantine/modals @mantine/notifications
```

### Setup

Wrap your application with `Plasmantine`.
It applies the Plasma theme and CSS variables, so you do not need a separate `MantineProvider`.

```tsx
import {Plasmantine} from '@coveord/plasma-mantine/plasmantine';
import '@mantine/core/styles.css';

function App() {
    return <Plasmantine>{/* your app */}</Plasmantine>;
}
```

Import the styles for any optional Mantine package you use.

```tsx
import '@mantine/notifications/styles.css';
```

### Usage

Render Plasma components anywhere inside `Plasmantine`.

```tsx
import {Button} from '@coveord/plasma-mantine';

function SaveButton() {
    return <Button.Primary>Save</Button.Primary>;
}
```
