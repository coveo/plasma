# ActionIcon

Icon-only button that can trigger actions and can show a disabled-state tooltip.

## Overview

Use `ActionIcon` when an action can be represented clearly by an icon and space is limited.

It works well in dense interfaces like tables, cards, toolbars, and repeated item rows where a full text button would add visual noise.

Don't use it when the action is primary, high-stakes, or unfamiliar enough to need visible text, or when several adjacent icon-only actions would be hard to tell apart.

## Emphasis variants

Use the Plasma sub-components to set emphasis. Don't use Mantine's `variant` prop directly.

- `ActionIcon.Primary` — most important compact action in a local context.
- `ActionIcon.Secondary`, `ActionIcon.Tertiary`, `ActionIcon.Quaternary` — decreasing emphasis.
- `ActionIcon.DestructivePrimary` — primary destructive action in a local context.
- `ActionIcon.DestructiveSecondary`, `ActionIcon.DestructiveTertiary`, `ActionIcon.DestructiveQuaternary` — decreasing emphasis for destructive actions. Use `DestructiveQuaternary` for low-emphasis removes in repeated rows.
- `ActionIcon.Group` — visually groups related icon actions together.

Use lower-emphasis variants for repeated row actions so they don't compete with page-level actions.

Only use destructive variants for actions that remove, delete, revoke, or otherwise negatively affect data.

## Async actions

Async `onClick` handlers are supported. The button shows a loading state while the promise resolves.

## Accessibility

- Icon-only actions need an accessible name. Set `aria-label` on the control or on the icon.
- Disabled actions should explain why they're unavailable using `disabledTooltip`.
- The icon can't be the only source of meaning when the action is ambiguous.

## Content guidance

**`aria-label`**

- Describe the action, not the icon: "Remove item" not "Trash".
- Use sentence case.
- Keep it short — 1–3 words is ideal.

**`disabledTooltip`**

- Explain why the action is unavailable, not just that it is: "You don't have permission to remove this item" not "Disabled".
- Write a full sentence. End with a period.
- Keep it under 20 words.
