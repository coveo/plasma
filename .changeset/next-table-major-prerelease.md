Start the next major prerelease line

This release starts the prerelease line for the next major version, which will rework the `Table` component. Prereleases are published under the `next` tag and may contain breaking changes before the stable release.

# Migration

Stay on the current stable version unless you want to try the prerelease. To try it, install the `next` tag of each package, for example `@coveord/plasma-mantine@next`. Breaking changes and their migration steps will be listed in the changelog as they land.
